# Port Scanner

## Overview
A simple cybersecurity tool built in Python to scan a target system and detect open ports.  
This project demonstrates basic network reconnaissance used in ethical hacking.

## Features
- Scans ports from 1 to 100
- Detects open ports on a target system
- Uses Python socket programming
- Lightweight and easy to run

## Technologies Used
- Python
- Socket Programming

## How to Run
1. Open terminal
2. Navigate to project folder
3. Run:

python port_scanner.py

4. Enter target IP or domain (example: 127.0.0.1)
